## Installation
**1. Clone the repository:**
```bash
   git clone https://github.com/nameissakthi/Portfolio.git
```

**2.  Navigate into the project directory:**
```bash
    cd Sakthivel-Portfolio
```

**3.  Install dependencies:**
```bash
    pnpm install
```

**4. Run the app:**
```bash
    pnpm run dev
```
